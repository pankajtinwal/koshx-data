# Koshx Data Feed (`koshx-data`)

Automated live data ingestion pipeline powering [Koshx](https://koshx.in).

## Features
- **Indian Stock Indices**: Intraday & EOD sector and theme benchmarks.
- **Institutional Activity**: Official NSE FII/DII Cash & Derivatives sentiment metrics.
- **MTF Candlestick Data**: 500+ Indian stock daily series for lightweight charts.

This repository is maintained automatically via GitHub Actions.
